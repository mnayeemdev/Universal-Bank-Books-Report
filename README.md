# 🏦 Universal Bank Books Report

### Bank Statement → Books of Accounts → Reconciliation → Audit Trail

**Universal Bank Books Report** is a free Python-based bank statement analysis and audit-assistance tool created to make the work of **Chartered Accountants (CAs), Auditors, Accountants, Finance Professionals and Businesses** easier.

> **The goal is simple: A CA or Auditor should not have to spend hours manually organizing and analysing bank statements.**

The software reads bank statements, identifies transactions, preserves source information, performs reconciliation and generates structured Excel reports for accounting and professional review.

---

## ❤️ Why I Created This

Bank statement analysis can involve a large amount of repetitive manual work.

Different banks provide statements in different formats, column structures, narration styles, Debit/Credit formats and PDF layouts.

This project was created to reduce that repetitive work.

The objective is to help professionals spend more time on:

- Verification
- Analysis
- Professional judgement
- Audit review

and less time on manual data preparation.

This is an **assistive tool**.

It does not replace the professional judgement of a Chartered Accountant, Auditor or Accountant.
